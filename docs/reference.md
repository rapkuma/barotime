## 1. 프로젝트 개요

- **목적**: 0.001초 오차 없는 실시간 서버시간 동기화와 네이비즘(Navyism) 스타일의 실시간 동시접속 및 응원 커뮤니티를 제공하는 웹 서비스.
- **주요 사용자**: 티켓팅 예매자(인터파크, 멜론티켓 등), 전국 대학교 수강신청 대학생, 명절 기차표(코레일, SRT) 예매자.
- **핵심 가치**:
  - 순우리말 '바로' (오차 없이 바로 맞는 시계) + 4글자 영문(BARO)으로 누구나 쉬운 접근성.
  - 0.001초 단위 틱오버(Tick-Over) 초정밀 동기화.
  - 정각 5초 전부터 울리는 계단식 카운트다운 사운드 & 시각적 글로우 뱃지.
  - 오늘/어제/누적 방문자 수 및 실시간 인기 접속처·응원 피드.

## 3. Supabase 데이터베이스 스키마 (DDL)

Supabase SQL Editor에서 실행된 커뮤니티 테이블 스키마입니다.

```sql
-- 1. 방문자 통계 테이블 (오늘, 어제, 누적)
CREATE TABLE IF NOT EXISTS public.site_stats (
    id TEXT PRIMARY KEY,               -- 'daily_YYYY-MM-DD' 또는 'total_visitors'
    visit_count BIGINT DEFAULT 0,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- 2. 실시간 응원 한마디 테이블 (Navyism 스타일 댓글창)
CREATE TABLE IF NOT EXISTS public.cheers (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nickname VARCHAR(50) DEFAULT '익명',
    content TEXT NOT NULL,
    target_name VARCHAR(100) DEFAULT '전체',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- 3. 실시간 동시 접속처 집계 테이블 (15분 활성 세션)
CREATE TABLE IF NOT EXISTS public.active_sessions (
    id TEXT PRIMARY KEY,               -- 클라이언트 고유 세션 ID
    target_name VARCHAR(100) NOT NULL, -- 확인 중인 사이트 이름 (예: 인터파크 티켓, 서울대학교 등)
    target_url TEXT NOT NULL,
    last_active TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- RLS (Row Level Security) 설정 및 공개 접근 허용
ALTER TABLE public.site_stats ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.cheers ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.active_sessions ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read site_stats" ON public.site_stats FOR SELECT USING (true);
CREATE POLICY "Allow public upsert site_stats" ON public.site_stats FOR ALL USING (true);

CREATE POLICY "Allow public read cheers" ON public.cheers FOR SELECT USING (true);
CREATE POLICY "Allow public insert cheers" ON public.cheers FOR INSERT WITH CHECK (true);

CREATE POLICY "Allow public read active_sessions" ON public.active_sessions FOR SELECT USING (true);
CREATE POLICY "Allow public upsert active_sessions" ON public.active_sessions FOR ALL USING (true);
```

## 4. 핵심 기술 아키텍처 & 알고리즘

### 4.1. 0.001초 틱오버(Tick-Over) 서버 동기화 알고리즘
- 일반적인 웹 시계는 `Date` 헤더 1초 단위만 받아오기 때문에 최대 999ms의 오차가 발생합니다.
- 바로(BARO)는 대상 웹 서버로 고주파 핑을 보내며 **초(Second)가 넘어가는 순간(0.000초 틱오버 시점)**을 감지합니다.
- 왕복 레이턴시(Round-Trip Time)의 절반을 보정하여 로컬 클럭의 정확한 오프셋(`serverTimeOffset`)을 계산, 1ms(0.001초) 단위 정밀도로 렌더링합니다.

### 4.2. 스마트 도메인 폴백 & DNS 해석 방어
- `ticket.auction.co.kr` 처럼 실제 웹 서버 DNS 레코드가 루트(`www.auction.co.kr`)로만 열려있는 경우 발생하는 `ENOTFOUND` 에러를 자동 감지합니다.
- 대상 도메인이 실패할 경우 자동으로 `www.*` 또는 메인 도메인으로 2차 폴백 조회를 시도하여 사용자가 어떤 주소를 입력해도 시계가 끊김 없이 동기화됩니다.

### 4.3. 전국 116+ 대학교 데이터셋 & 초성 검색 엔진
- `src/data/universities.ts`
- 서울대, 연세대, 고려대부터 지역 거점 국립대, 특수대학(KAIST, UNIST 등)까지 전국 수강신청 주소 탑재.
- 한글 초성 검색(예: `ㅅㅇㄷ` → 서울대학교, `ㅋㄹㅇ` → 코레일) 지원.
- 검색어 우선순위 스코어링을 통해 동음 및 유사어 중 가장 대중적인 사이트가 상위에 노출되도록 최적화.

### 4.4. 사운드 및 비주얼 카운트다운 알림
- Web Audio API 기반 오실레이터(Oscillator)를 사용하여 외부 mp3 파일 로딩 지연 없이 0ms 즉시 재생.
- 5초 전부터 0초 정각까지 계단식 주파수 상승(440Hz → 494Hz → 554Hz → 659Hz → 740Hz → 880Hz 트라이앵글파).
- 시계 테두리 및 배경 글로우 펄스 효과 동기화 (Amber → Orange → Red → Rose → Emerald).
